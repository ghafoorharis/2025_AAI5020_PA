Network Architecture

VGG16-based NetVLAD architecture for visual place recognition. The network extracts local features, performs soft-assignment to cluster centroids, and aggregates into global descriptors.

Abstract

This project presents a comprehensive implementation of NetVLAD (Network VLAD) for visual place recognition and camera pose estimation. We develop a VGG16-based NetVLAD architecture that learns discriminative global image descriptors through triplet ranking loss. The system achieves robust visual localization by combining learned embeddings with geometric verification for accurate camera pose recovery. Our approach demonstrates strong performance on the Pittsburgh dataset, achieving 20.5% Recall@1 and 57.1% Recall@10 for place recognition, with geometric pose estimation achieving sub-meter accuracy in favorable conditions.

Methodology

1. NetVLAD Architecture

  • VGG16 backbone for feature extraction
  • Soft-assignment of local features to cluster centroids
  • Global descriptor aggregation using VLAD pooling
  • Dimensionality reduction for efficient retrieval

2. Training Strategy

  • Triplet ranking loss with hard negative mining
  • Margin-based formulation for embedding learning
  • End-to-end training with gradient descent

3. Pose Estimation Pipeline

  • Image retrieval using learned embeddings
  • Feature matching between query and database images
  • Two-view geometry estimation using 8-point algorithm
  • Essential matrix decomposition for pose recovery

Conclusion

This project successfully demonstrates the effectiveness of NetVLAD for visual place recognition and camera pose estimation. The combination of learned embeddings with geometric verification provides a robust framework for visual localization. While the system achieves reasonable performance on the Pittsburgh dataset, there are opportunities for improvement through better feature matching, more sophisticated geometric verification, and potentially incorporating temporal consistency for video sequences. The results validate the potential of deep learning approaches for visual localization tasks in real-world scenarios.
