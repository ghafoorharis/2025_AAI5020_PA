# NetVLAD Project Website

This folder contains the website files for the NetVLAD-based Visual Place Recognition and Camera Pose Estimation project.

## Structure

```
website/
├── index.html              # Main HTML page
├── static/
│   ├── css/
│   │   ├── index.css       # Custom styles
│   │   ├── bulma.min.css   # Bulma framework (placeholder)
│   │   ├── bulma-carousel.min.css
│   │   ├── bulma-slider.min.css
│   │   └── fontawesome.all.min.css
│   ├── js/
│   │   ├── index.js        # Custom JavaScript
│   │   ├── bulma-carousel.min.js
│   │   ├── bulma-slider.min.js
│   │   └── fontawesome.all.min.js
│   └── images/
│       ├── netvlad_network.png
│       ├── example_visualzations_image_retrieval.svg
│       └── task3_result_graph.png
└── README.md
```

## Features

- **Professional Design**: Based on NeurIPS conference template
- **Responsive Layout**: Works on desktop and mobile devices
- **Clean Results Presentation**: Tables and graphs for performance metrics
- **Network Architecture**: Visual representation of the NetVLAD model
- **Methodology Section**: Detailed explanation of the approach
- **Results Visualization**: Main visualization showing retrieval results

## Usage

1. Open `index.html` in a web browser
2. For GitHub Pages deployment, ensure all static files are properly linked
3. Update the GitHub repository links in the HTML file

## Customization

- Update author information in the header section
- Modify the abstract and methodology sections as needed
- Add or remove result tables based on your specific results
- Update image paths if you add new visualizations

## Dependencies

The website uses:
- Bulma CSS framework for styling
- FontAwesome for icons
- jQuery for JavaScript functionality
- MathJax for mathematical notation (if needed)

Note: The CSS and JS framework files are currently placeholders. For full functionality, you would need to download the actual minified versions of Bulma and FontAwesome.
